GapHunter — a reactive cross-pool arbitrage sentinel

A Reactive Smart Contract on Lasna watches two Uniswap V2 pools on Base Sepolia. When their prices diverge beyond a fee-adjusted threshold it orders the arbitrage itself — no server, no keeper, no human trigger. This page reads the live chain state and the recorded run ledger.

Latency is origin event → callback executed, from Base Sepolia block timestamps (1-second granularity). The full machine-readable ledger, including pool reserves before/after and per-run balances, is evidence/runs.json in the repository.

Testnet demonstration: both venues are self-deployed Uniswap V2 pools and GTA/GTB are valueless demo tokens; gaps are opened by our own whale swaps. What is proven is the pattern — a contract that watches, decides and executes with no off-chain component — not mainnet profitability. Live state is read directly from the public Base Sepolia RPC by your browser; nothing on this page is served by us.
